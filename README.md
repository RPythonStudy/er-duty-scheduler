# 응급실 근무 관리 시스템 설치 및 사용 가이드

## 1. 초기 설정 (Google Sheets)
1. 새 구글 스프레드시트를 생성합니다.
2. 상단 메뉴 **확장 프로그램** > **Apps Script**를 클릭합니다.
3. `Code.gs`의 내용을 복사하여 스크립트 에디터에 붙여넣습니다.
4. 스크립트를 저장하고, 'ER 근무 관리' 메뉴가 나타날 때까지 시트를 새로고침합니다 (혹은 `onOpen` 함수 실행).

## 2. 시트 구성
스크립트가 처음 실행될 때 자동으로 필요한 시트가 없는 경우 생성하려고 시도하지만, 수동으로 확인해 주세요.

### `Config` 시트
| A | B |
|---|---|
| Year | 2024 |
| Month | 5 |
| Calendar ID | (캘린더 설정에서 ID 복사) |

### `Holidays` 시트
| A |
|---|
| 날짜 (YYYY-MM-DD) |
| 2024-05-05 |
| ... |

### `Doctors` 시트 (선택사항)
이메일 대신 이름을 표시하려면 이 시트를 추가하세요.
| A | B |
|---|---|
| 이름 | 이메일 |
| 김철수 | kim@example.com |
| 이영희 | lee@example.com |

## 3. 사용 방법

### 근무표 슬롯 생성
1. `Config` 시트에서 연/월을 설정합니다.
2. 메뉴에서 **ER 근무 관리** > **근무표 슬롯 생성**을 클릭합니다.
3. 지정된 캘린더에 '[모집] 평일 오전' 등의 이벤트가 생성됩니다.

### 의사 신청 (사용자)
1. 의사들에게 공유된 캘린더에서 비어있는 `[모집]` 이벤트를 클릭합니다.
2. 자신을 **참석자(Guest)**로 추가하고 저장합니다.

### 확정 처리 (관리자)
1. 메뉴에서 **ER 근무 관리** > **신청 내역 동기화**를 클릭합니다.
2. 시스템이 참석자가 있는 이벤트를 감지하여 확정 상태로 변경하고, `Master_Log` 시트에 기록합니다.
* *팁: 이 기능은 Apps Script 트리거를 이용하여 10분, 1시간 단위로 자동 실행되게 설정할 수 있습니다.*

## 4. 테스트 체크리스트
설치 후 다음 순서대로 테스트해보세요.

1.  **시트 설정**: `Config` 시트에 현재 연도/월 입력, `Calendar ID`에 새 테스트용 캘린더 ID 입력.
2.  **슬롯 생성**: `근무표 슬롯 생성` 메뉴 실행 -> 캘린더에 '[모집]' 이벤트 30+개 생성 확인.
3.  **신청 테스트**:
    *   스마트폰이나 웹 캘린더에서 '[모집]' 이벤트 클릭.
    *   '참석자(Guest)'에 본인 이메일 추가 후 저장.
4.  **확정 실행**: 메뉴 `신청 내역 동기화` 실행 -> 알림창 메시지 확인.
5.  **결과 확인**:
    *   캘린더 이벤트 제목이 `[확정] 본인이름`으로 바뀌었는지 확인.
    *   `Master_Log` 시트에 신청 내역이 한 줄 추가되었는지 확인.
