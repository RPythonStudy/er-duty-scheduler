# 응급실 근무 관리 시스템 (Web App 버전)

이 시스템은 구글 캘린더를 기반으로 작동하지만, **사용자(의사)는 별도의 웹 페이지(Web App)를 통해 로그인 없이 간편하게 당직을 신청**할 수 있도록 설계되었습니다.

## 1. 시스템 구조
*   **Google Sheets**: 관리자용 설정(연/월, 캘린더ID) 및 로그 저장소.
*   **Google Calendar**: 실제 근무표 데이터베이스. (모든 상태는 캘린더에 저장됨)
*   **Google Apps Script (Web App)**: 사용자와 캘린더를 연결하는 중계 서버 역할.

## 2. 초기 설정

1.  **시트 준비**:
    *   `Config` 시트: A열(Key), B열(Value)
        *   `Year`: 2024
        *   `Month`: 5
        *   `Calendar ID`: (구글 캘린더 ID)
    *   `Holidays` 시트: 휴일 날짜 목록 (YYYY-MM-DD)

2.  **스크립트 설정**:
    *   `Code.gs`: 백엔드 로직
    *   `index.html`: 프론트엔드 화면
    *   위 두 파일이 에디터에 있어야 합니다.

3.  **웹 앱 배포 (필수)**:
    *   우측 상단 [배포] > [새 배포] > [웹 앱] 선택.
    *   **다음 사용자로 실행**: `나(Me)` (관리자 권한)
    *   **액세스 권한**: `모든 사용자(Anyone)`
    *   생성된 URL을 복사하여 의사들에게 공유합니다.

## 3. 사용 방법

### 관리자 (Admin)
1.  구글 스프레드시트 메뉴 > **ER 근무 관리** > **근무표 슬롯 생성**을 실행합니다.
2.  해당 월의 빈 슬롯들이 구글 캘린더에 생성됩니다. (`[모집] 평일 오전` 등)

### 의사 (User)
1.  공유받은 **웹 앱 URL**로 접속합니다.
2.  달력에서 초록색 **[신청]** 버튼(빈 자리)을 클릭합니다.
3.  자신의 이름을 입력하고 **[신청하기]**를 누릅니다.
4.  즉시 신청이 확정되며, 버튼이 회색 **[이름]**으로 변경됩니다.

## 4. 문제 해결
*   **화면이 안 뜰 때**: `index.html` 파일이 에디터에 있는지 확인하고, 배포 버전을 '새 버전'으로 업데이트했는지 확인하세요.
*   **신청이 안 될 때**: `Config` 시트의 캘린더 ID가 올바른지, 해당 캘린더에 대한 쓰기 권한이 있는지 확인하세요.
